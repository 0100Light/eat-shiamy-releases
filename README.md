# ET-shiamy

免安裝、不需管理員權限的第三方**嘸蝦米輸入法**（Windows only）。

**這個 repo 只放釋出的版本，沒有原始碼。**
到 [Releases](https://github.com/0100Light/eat-shiamy-releases/releases/latest)
下載 `EatShiamy-x.y.z.zip`。

（GitHub 會在每個 release 底下自動附一個 `Source code (zip)`，
那是它自己加的、內容是空的，不要下載那一個。）

## 安裝

1. 下載 `EatShiamy-x.y.z.zip`
2. 解壓縮到任何你有寫入權限的資料夾（**不要放在 `C:\Program Files\` 底下**）
3. 執行裡面的 `EatShiamy.exe`

整個資料夾就是程式本身，搬到哪裡都能跑，也可以放隨身碟。
要移除就把資料夾刪掉，不會在系統裡留下任何東西 ——
它不寫登錄檔、不裝服務、不需要管理員權限。

詳細用法看資料夾裡的 `manual.html`。

### 第一次執行會被 Windows 攔下來

因為這支程式沒有數位簽章（那需要付費憑證）。

- **SmartScreen**「Windows 已保護您的電腦」→ 點「**其他資訊**」→「**仍要執行**」
- **Smart App Control**（Windows 11 全新安裝預設開啟）會直接擋掉而且沒有放行選項。
  只能先把它關掉，或改用其他輸入法。

另外**第一次啟動會比較慢**（十幾秒），那是 Windows Defender 在掃描
資料夾裡的幾百個檔案。掃過一次就不會再慢了。

## 自動更新

程式會自己檢查有沒有新版、自己下載，然後在狀態列上顯示「重啟更新」，
點一下才會套用 —— 不會在你打字打到一半自己重開。

更新前的版本會完整留在 `plugin\rollback\`，隨時可以換回去：

- 新版還能用：執行 `EatShiamy.exe --rollback`
- 新版開不起來：雙擊 `plugin\rollback\rollback.cmd`

不想自動更新的話，把 `plugin\window_config.json` 裡的
`update_check` 改成 `false`。

### 0.1.0 升上來要手動裝一次

0.1.1 把主程式從 `shiamy.exe` 改名成 `EatShiamy.exe`，而 0.1.0 認得的檔名
是舊的，它會拒絕這一包並顯示「更新失敗」。

**原本的安裝不會受損** —— 失敗發生在解壓的第一步，那時已經下載完、
校驗也過了，但還沒碰到任何現役檔案。

請自己下載解壓一次，然後把舊資料夾裡的 `plugin\window_config.json`
複製到新的 `plugin\` 底下，視窗位置、字級、配色就會跟著過去。
其餘不用搬：`plugin\cache\` 會自己重建，`plugin\rollback\` 是舊版的備份、
跟新安裝無關。確認新的跑起來正常之後，把舊資料夾刪掉。

0.1.1 之後的更新恢復自動。

## 這是什麼、不是什麼

它**不是** TSF/IMM 輸入法模組 —— 那種要註冊到系統、需要管理員權限。
這支是外掛式的做法：攔截按鍵之後合成輸入，再用一條置頂的狀態列當候選字視窗。
代價是它跟系統輸入法是兩套東西，切換方式也不一樣（預設單按 Shift）。

## 站在誰的肩膀上

程式是重新寫的，但兩個關鍵決定不是我想出來的。

### 偽．蝦米 XLiu（Luke Chang，2008）—— 截字的做法照它走的

它示範了關鍵的一件事：不必做成 TSF 輸入法、不必碰鍵盤配置，
光靠「逐鍵向系統註冊要攔哪些鍵」加上「合成輸入送字」，
就做得出一支免安裝、不需要管理員權限的嘸蝦米。

那正是這個專案唯一走得通的路線 —— TSF 輸入法要註冊到系統、需要管理員權限，
那條路一開始就封死了。要攔哪些鍵、什麼時候攔、切成英數的時候怎麼把鍵盤
完整還給系統，都是從它的行為推導出來的。

### 倚天中文輸入法（Python 復刻版）（張書維）—— UI 的原型

用 Tkinter 畫一條置頂的狀態列當候選字視窗、UI 跑在自己的執行緒上、
跟核心之間用 queue 單向通訊 —— 這套結構沿用至今，
只是把注音換成嘸蝦米，並重做了攔鍵與送字兩層。

（兩份作品都沒有找得到的公開位址可以連，所以這裡只寫清楚名字。）
