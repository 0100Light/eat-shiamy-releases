ET-shiamy 使用說明

免安裝、不需管理員權限的第三方嘸蝦米輸入法。

開始使用

  1. 把整個 EatShiamy 資料夾解壓到任何地方（隨身碟也可以）。
  2. 雙擊裡面的 EatShiamy.exe。
  3. 螢幕底部、工作列正上方會出現一條藍色狀態列（寬度約半個螢幕、置中）， 那就是輸入法的候選字視窗。

不需要安裝、不需要管理員權限、不會寫進登錄檔。整個資料夾刪掉就等於移除乾淨。

資料夾要整個搬。EatShiamy.exe 需要旁邊的 _internal\ 與 tables\ 才能執行，只複製 exe 出來會打不開。

關閉：在狀態列上按右鍵，選最後一項 結束。沒有系統匣圖示，也不會開機自動啟動。想開機自動啟動的話，把 EatShiamy.exe 的捷徑放進「啟動」資料夾（按 Win+R 輸入 shell:startup）。

第一次執行會被 Windows 攔下來

因為這支程式沒有數位簽章 —— 那需要付費憑證。程式本身沒有問題， Windows 只是不認得它。

  • SmartScreen：出現「Windows 已保護您的電腦」時， 點「其他資訊」→「仍要執行」。
  • Smart App Control（Windows 11 全新安裝預設開啟）： 會直接擋掉，而且沒有放行的選項。 只能先把它關掉，或是改用其他輸入法。

解壓縮的位置要有寫入權限，不要放在 C:\Program Files\ 底下。程式要在自己的資料夾裡寫設定與快取（plugin\）， 放在那裡會因為沒有管理員權限而失敗。

第一次啟動會很慢，這是正常的

在一台電腦上第一次執行大約 10～15 秒，之後每次不到半秒。 兩個原因：

  • Windows 掃描新程式（約 13 秒，佔絕大部分）—— Windows Defender 會把第一次見到的程式整包掃過一遍。這是作業系統的行為， 跟輸入法本身無關。
  • 建立字根表快取（約 0.2 秒）—— 程式把字根表編譯成 plugin\cache\ 底下的檔案，之後開機直接讀快取。

掃描的結果是記在檔案本身上的，所以同一台電腦裡把資料夾搬到別的位置、 或複製一份出來，都不會再慢一次（實測約 1 秒）。換一台電腦才會重來一次。

plugin\ 資料夾隨時可以整個刪掉，只會讓下一次開機慢個零點幾秒。

打字

狀態列左邊顯示 嘸蝦米 時就是中文輸入狀態。打字根碼， 候選字會即時出現在狀態列上。

按鍵作用
字根鍵 a～z 加上 [ ] ; ' , .，共 32 顆
- = 不是字根，但一樣打得進去。它們拆不出中文字，是留給中英混輸用的 —— 打 e-mail 這種字串，打完按 Enter 原樣送出
Space 送出目前這一頁的第一個候選字。 如果打了拆不出字的碼，按 Space 會清空重來、不送出任何東西
1～9 選目前這一頁的第 n 個候選字。選不到的時候就是打數字 —— 沒有候選字、或這一頁根本沒有第 n 個，數字就直接打進去， 所以 a1、-2024 這種也打得出來
← / → 上一頁 / 下一頁候選字。只有正在打字的時候才會被接管， 沒在打字時方向鍵就是移動游標
Backspace退掉一個字根
Esc整串清掉，不送出
Enter 把目前打的碼原樣當英文送出（中英混輸用，見下節）

沒在打字的時候，這些鍵全部是原生的。 按數字就是打數字、按 Enter 就是換行、按 Space 就是空白、 按方向鍵就是移動游標。輸入法只在「正在組字」的那一瞬間才接管它們。

表裡的例外是 - 與 =：它們隨時都會打進緩衝區， 所以在中文狀態下要打出這兩個符號，得按完再按 Enter。

標點符號

標點也是用字根碼打的，例如 , 出「，」、,, 出「「」、 ' 出「、」。打完按 Space 或數字選字。

想打半形標點，打完直接按 Enter —— 例如按 , 再按 Enter 就會送出半形的 ,。

中英混輸

不用切模式就能夾雜英文：

  • 在嘸蝦米模式下按 Shift+字母，大寫字母會存進緩衝區。
  • 接著繼續打字母把單字打完。
  • 按 Enter 原樣送出。

例如 Shift+H 然後 ello 再按 Enter，送出 Hello。

- = 與（選不到候選字時的）數字也會進緩衝區， 所以 e-mail、x=y、a1 都是照打再按 Enter。

打到一半才發現接下來要打的是一長串英文，就輕按一下 Shift —— 已經打進去的字母會原樣送出，同時切到英數模式， 不必先按 Enter 再按 Shift。

切換中文／英數

輕按一下 Shift 再放開（半秒內、期間沒碰到別的鍵） 就會在「嘸蝦米」與「英數」之間切換。也可以直接點狀態列最左邊 那一格。

英數模式下打一鍵出一個字母，不組字也不用按 Enter。而且半形英數模式下 輸入法完全不攔截鍵盤，打字手感跟沒開輸入法一模一樣。

如果切換的當下還有字碼沒送出，兩種切法的處置不一樣：

  • 按 Shift 切換 —— 把那些字母原樣送出， 等於順手替你按了一次 Enter（一樣不轉簡體，全形設定照舊生效）。
  • 點狀態列或用右鍵選單切換 —— 那些字碼直接丟掉。 因為滑鼠一點下去，游標焦點就已經離開你正在打字的地方， 這時送字只會送到不見。

如果覺得單按 Shift 太容易誤觸，可以關掉它 —— 見下面的 設定，把 shift_toggles_mode 改成 false，改用點狀態列切換。

狀態列

嘸蝦米半形 cox　1蝦 繁 ＋－停

訊息只在你沒打字的時候出現。一開始打字根碼，訊息就讓開， 中間那塊回去顯示候選字；送出字、緩衝區空了以後它自己會回來。所以它不會擋住輸入， 也不會因為你沒理它就消失。

整條的顏色代表現在是什麼狀態：中文一種顏色、英數另一種， 有需要你處理的事（鍵衝突、可以重啟更新、更新失敗）時整條會換成第三種， 停用時整條變灰。

十一種配色實際長什麼樣（含滑鼠移上去的顏色、深淺桌面）攤成一頁在 配色一覽，跟這份說明放在同一個資料夾，離線也開得起來。

選單最上面那一行是版本號。用意見回饋 回報時它會自動附上，不必自己抄。

除了原色那一種，配色都轉錄自 vim-airline（MIT 授權）的同名配色。 少數幾種在螢幕上的對比不高——那是原本的配色就長那樣，刻意保留； 覺得看不清楚就換一種。

搬移與調整寬度

  • 搬移：在狀態列上任何地方按住拖曳。
  • 改寬度：把游標移到狀態列最左或最右邊緣， 游標變成左右箭頭時拖曳。
  • 放開滑鼠就會自動記住位置、寬度與字體大小。

候選字每頁幾個，是依狀態列寬度即時算出來的。 把狀態列拉窄，每頁就少幾個字、頁數變多；拉寬則相反（最多 9 個）。 所以按 3 選第三個字之前，看的是螢幕上目前排出來的順序。

候選字的 < > 箭頭

右邊出現 > 代表後面還有候選字，按 → 翻頁； 出現 < 代表前面還有，按 ← 翻回去。

回報問題與建議

右鍵選單的意見回饋底下有兩項： 回報問題與功能建議。 點下去會用你的瀏覽器打開 ET-shiamy 在 GitHub 上的頁面， 標題與內文都已經先填好，你只要補上發生了什麼事再送出。 需要一個免費的 GitHub 帳號。

內文最底下那段診斷資訊是自動帶入的：版本、Windows 版本、 目前的模式與配色、有幾顆鍵被別的程式佔走、字根表載了幾筆。 這些就是排查問題時最常要回頭問的東西。

裡面不包含你打過的字，也不包含任何檔案路徑。 內容在送出之前都看得到、改得動—— 按下網頁上的送出鈕之前，什麼都還沒有送出去。

打不開瀏覽器的話，也可以自己到 github.com/0100Light/eat-shiamy-releases/issues 開一則。

全形與繁簡

全形

點「半形」切成「全形」之後：

  • 英數模式下，每一個字元都變全形，包含空白（　）、 數字（１２３）與符號（！＠＃）。
  • 嘸蝦米模式下，全形只作用在送出的文字 —— 也就是按 Enter 送出的那串英文（- = 也在裡面）。中文字本來就是全形寬度。 這時候直接打的數字與 / \ 仍然是半形， 因為中文模式必須把那些鍵留給你打字根。

繁簡

點 繁 切成 簡，送出的中文字會轉成簡體 （例如「蝦」→「虾」）。按 Enter 送出的英文不會被轉。

全形與繁簡兩個設定都會被記住，下次開啟維持原樣。中英模式與停用狀態不會記住， 每次開啟都是嘸蝦米、啟用中。

設定

所有設定都存在 plugin\window_config.json。大部分用狀態列調整就好， 以下幾項目前只能用記事本直接改（改完要重開程式）：

項目預設說明
shift_toggles_modetrue 單按 Shift 切換中英。改成 false 可完全關掉
width0 狀態列寬度，0 表示螢幕寬的一半
x / y-1 / -1 狀態列位置。x: -1 表示水平置中， y: -1 表示下緣貼齊工作列上側
font_size18 只接受 12、14、16、18、20、24、28、32
fullwidth / to_simplifiedfalse 開機時的全形／簡體狀態

設定檔刪掉就會全部回到預設值，不會有其他影響。 改壞了也不會讓程式打不開 —— 程式讀不懂設定檔時會直接用預設值啟動。

疑難排解

標點符號底下有一條虛線，要再按 Enter 才會真的出現

這是系統內建的微軟注音攔截造成的，不是本程式的問題。 新版微軟注音會把我們送出的標點收進它自己的組字狀態。漢字不受影響，只有標點會這樣。

解法：打開微軟注音的相容性選項 ——

設定 → 語言和區域 → 中文(繁體，台灣) → 語言選項 → 微軟注音 → 鍵盤選項 → 一般 → 相容性：使用先前版本的 Microsoft 注音（打開）

這是改 Windows 的設定，不是改本程式。Windows 更新有可能把它重設回去， 換一台電腦也要重設一次。

狀態列顯示「N 鍵衝突」

有 N 顆鍵被其他常駐程式註冊成全域快速鍵了，本程式搶不到。 那幾顆鍵打下去會直接輸出原本的字元，不會進候選。

這行字出現在狀態列中間、沒在打字的時候，整條也會換成事件的顏色。 一開始打字它就讓開，緩衝區清空後再回來 —— 它是持續存在的事實， 不會自己消失。

常見來源是螢幕截圖工具、錄影軟體、遊戲平台、巨集工具。把那些程式的快速鍵改掉， 或先關掉它們再開本程式。

在工作管理員、登錄檔編輯器裡打不出中文

那些視窗是以系統管理員權限執行的，Windows 不允許一般權限的程式 送字進去。這是作業系統的安全機制，任何免安裝輸入法都一樣。

在那些視窗裡本程式等於不作用，鍵盤會是原生的英文鍵盤 —— 不會發生「打了字卻不見」的情形。

雙擊沒反應

多半是資料夾不完整（缺 _internal\ 或 tables\）。 開 PowerShell 切到該資料夾，執行：

.\EatShiamy.exe --check

它會印出詳細的檢查結果並指出缺什麼，不會攔鍵盤也不會開視窗。 （程式是無主控台打包的，直接雙擊看不到訊息，一定要從終端機呼叫。）

全螢幕遊戲裡打不出字

獨佔全螢幕模式的遊戲很可能不吃合成輸入。這一點我們沒有實測過， 如果遇到，改用視窗模式或無邊框視窗模式試試。

單按 Shift 常常誤切模式

按住 Shift 用滑鼠選字、或按 Ctrl+Shift 切換系統輸入法時，本程式都不會誤判成單按。如果還是覺得容易誤觸， 把設定裡的 shift_toggles_mode 改成 false 關掉它。

自動更新

程式會在啟動十秒後、之後每天一次，到 GitHub 看看有沒有新版。 發現新版就自動下載，但不會自己重開 —— 輸入法重開的那幾秒鍵盤會回到原生狀態，打到一半被打斷很惱人， 所以什麼時候套用由你決定。

不想等的話，右鍵選單的更新 → 立即檢查更新隨時查得動，就算你把 自動檢查更新勾掉了也一樣 —— 勾掉的只是 「它自己跑去連網」這件事。

中間那塊顯示意思點下去
檢查更新中…正在查（只有你自己按立即檢查更新時才會看到） 不能點，一下就好
已是最新版本 0.1.1查過了，沒有更新可用 不能點，五秒後自己消失
查不到更新資訊連不上更新伺服器 不能點，五秒後自己消失。過一陣子會自動再試
新版 0.1.1發現新版了開始下載（通常不必點，它會自己下載）
下載 42%下載中不能點，等它跑完
解壓中在檢查與解壓縮不能點
重啟更新準備好了點它就會重開並更新
更新失敗出了問題再點一次重試。把滑鼠停上去會顯示原因

把滑鼠停在訊息上，會顯示這一版改了什麼。「重啟更新」與「更新失敗」 兩種狀態會讓整條狀態列換色，因為那兩種需要你動手；前三種只是講一句話， 整條的顏色不會動。

背景那次每天一次的檢查不會跳任何訊息。沒查到新版就 安安靜靜地過去 —— 每天彈一次「已是最新版本」只是打擾。只有你自己按下 立即檢查更新時才會回報結果。

更新後第一次啟動會比較慢（可能十幾秒）。那是 Windows Defender 在掃描剛換上去的幾百個新檔案，掃過一次就不會再慢了。這是正常的。

tables\ 裡隨附的碼表會被換成新版。 那些檔案由這個程式維護，更新時一律以新版為準（內容本來就一樣的不會白寫一次）。 所以請不要直接編輯它們 —— 你的修改會在下次更新時消失。 自訂字根的做法之後會另外提供。

回到上一版

更新之前的那一版會完整保留在 plugin\rollback\ 裡（大約佔 27MB），隨時可以換回去。

情況怎麼做
新版還能用，但你想退回去 右鍵選單的更新 → 回復上一版，或在資料夾裡開命令提示字元執行 EatShiamy.exe --rollback
新版根本開不起來 雙擊 plugin\rollback\rollback.cmd

兩種做法都是對調而不是覆蓋，所以換回去之後還可以再換成新版， 來回都不會弄丟東西。

不想留這份備份的話，整個 plugin\rollback\ 刪掉就好， 只是以後沒辦法一鍵換回去而已，不影響更新本身。

不想自動更新

打開 plugin\window_config.json，把 update_check 改成 false，重開程式就不會再自動檢查了。 要查的時候還是可以手動執行 EatShiamy.exe --check-update。

目前還沒有的功能

  • 中文詞組 —— 一次只能打一個字，還不能連打詞組或造詞。
  • 英文候選補全 —— 英文只能靠 Shift+字母 打完再按 Enter。
  • 唯一候選自動送出 —— 即使只有一個候選字也要按 Space。
  • 快打（簡碼）模式、VRSF 選字鍵。
  • 設定視窗 —— 部分設定只能直接編輯 JSON 檔。
  • 系統匣圖示、開機自動啟動選項。
